# Quick Start (2 minutes)

For someone using Devin/Claude Code for the first time.

---

## **Setup (Do Once)**

1. **Download vizbuilder:** https://github.com/shankarece/vizbuilder/releases
2. **Extract to:** `C:\vizbuilder`
3. **Open Power BI Desktop** with your `.pbix` file
4. **Open Devin** (https://devin.ai) or Claude Code

---

## **Build Your Dashboard (5 minutes)**

### **In Devin, say:**

```
"I have a Power BI file at C:\work\Sales.pbix

Please build a dashboard with:
- Total Sales card
- Sales by Region bar chart
- Sales by Category donut chart

Make it fit on one page"
```

### **Devin will:**
1. ✅ Read your PBIX file
2. ✅ Generate dashboard code
3. ✅ Build and validate
4. ✅ Show: "Built: C:\work\Sales_out.pbix"

### **You do:**
1. Open `C:\work\Sales_out.pbix` in Power BI Desktop
2. See your dashboard
3. Save: `File → Save`

---

## **Make Changes**

In Devin, ask:

```
"Make the chart wider"
"Add a Region slicer"
"Change to 3 KPIs instead of 1"
"Add page 2 with details"
```

Devin rebuilds. You review in Desktop. Done!

---

## **Common Tasks**

| Task | Ask Devin |
|------|-----------|
| Simple dashboard | "Build a dashboard with KPI and chart" |
| 2 pages | "Create two pages: summary and detail" |
| With slicers | "Add a Region slicer to filter charts" |
| Adjust layout | "Make everything fit on one page" |
| Add measures | "Add Revenue = Sum(Sales)" |
| Security | "Add row-level security by region" |

---

## **That's it!**

No coding needed. Just describe what you want. Devin handles the rest.
